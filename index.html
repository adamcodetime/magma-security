🍏 Desktop for macOS 🐍 Windows Python Source

🚀 Windows Source Installation Guide

  1. Download and install Python 3.12.1 from the official release site (ensure the checkbox to add Python to PATH is selected).
  2. Open your terminal/command prompt and download the graphical UI toolkit: pip install customtkinter
  3. Navigate to your downloaded script location and launch the program frame: python magma.py
